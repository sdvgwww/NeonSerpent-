Nebula Dodge 
Управление:
  WASD / стрелки — движение змейки
  Shift           — рывок (dash) с перезарядкой
  ЛКМ (мышь)      — импульс: оглушает всех дронов в радиусе (тратит энергию)
  ПКМ             — пауза / продолжить
  Space           — пауза / новая игра (после Game Over)
  R               — рестарт в любой момент
  Esc             — выход

Цель: набрать как можно больше очков, не потеряв все жизни.
